# Heart Disease Prediction Using an Artificial Neural Network

A supervised machine learning project exploring binary heart disease classification using structured clinical data.

## Overview

This project uses the UCI Heart Disease dataset to investigate whether an artificial neural network (ANN) can learn patterns associated with the dataset's heart disease target. It provides a practical introduction to building, training and evaluating neural networks for tabular classification rather than image-based tasks.

## Project workflow

1. Load and inspect the UCI Heart Disease dataset.
2. Prepare the clinical features and target for model training.
3. Train an artificial neural network on the training data.
4. Evaluate classification performance on held-out data.

## Concepts explored

- Tabular data classification
- Artificial neural networks
- Supervised learning
- Model training, testing and evaluation

## Getting started

Obtain the UCI Heart Disease dataset and set up the Python environment required by the implementation. Use the repository's model code or notebooks to prepare the data, train the ANN and evaluate its predictions. The dataset is available from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/45/heart+disease).

## Scope

This is an educational machine learning project, not a clinically validated diagnostic tool. Its outputs should not be used to make medical decisions or estimate an individual's risk of a future heart attack.
